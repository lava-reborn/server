# client/objects — свои объекты для локаций

Картинки, из которых получаются новые объекты локаций: флажок, вывеска, дом,
костёр с анимацией. Каждая выкатка собирает из них файлы спрайтов и кладёт в
релиз клиента (`client/build.py`, код в `tools/custom_objects.py` и
`tools/swfgen.py`). Объект `c_test_flag` — образец, ни одна локация его не
ставит.

## Как добавить объект

1. id: `c_` и дальше латиница в нижнем регистре, цифры и `_`, до 40 знаков.
2. Картинки — в `client/objects/<id>/`: `0.png`, `1.png`, ... Одна картинка —
   неподвижный объект, несколько — анимация.
3. Запись в `manifest.json`:

   ```json
   "c_well": {
     "title": "Колодец",
     "frames": ["0.png"],
     "anchor": [48, 90],
     "front": [[-1, 0], [0, 0], [1, 0]],
     "footprint": [[0, 0], [1, 0]]
   }
   ```

4. Проверка: `python3 tools/custom_objects.py check --base client/base.txt --base client/extra.txt`.

То же умеет редактор локаций (`tools/location_editor.py`).

## Поля записи

| Поле | Что это |
|---|---|
| `title` | название, до 80 знаков |
| `frames` | картинки из папки объекта по порядку |
| `fps` | для анимации: картинок в секунду, 1..25 |
| `anchor` | точка картинки `[x, y]`, которая стоит в центре клетки |
| `front` | линия глубины: клетки относительно якоря, по умолчанию `[[0, 0]]` |
| `footprint` | непроходимые клетки относительно якоря, по умолчанию пусто |
| `kind` | `sprite` (по умолчанию) или `background` — фон плиткой |
| `note` | заметка для людей |

Картинки: PNG без чересстрочности или baseline JPEG, сторона до 2880 точек,
картинка до 8 МБ, вся папка до 32 МБ. В папке объекта только его картинки, и
каждая папка должна быть в `manifest.json`. id не может совпадать с файлом
оригинальной игры.

## Как поставить объект в локацию

```
python3 tools/custom_objects.py place c_test_flag 30 65
```

Команда печатает элемент `<sprite ... type="ext">` для XML локации и клетки
для `<obstacles>`. Локация с объектом кладётся в
`data/locations/static/<id>.xml`: её читает и сервер, и сборка релиза.
Игроки увидят объект после выкатки и перезапуска лаунчера.

## Проверки

- `python3 tools/test_swfgen.py` и `python3 client/test_client.py` — в CI.
- `bash tools/flash_headless/run.sh <локация.xml>` — по желанию, настоящий
  Flash Player рисует локацию без окон.
