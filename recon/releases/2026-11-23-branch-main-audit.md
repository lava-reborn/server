## Повторное код-ревью

Учтены замечания прошлых PR: атомарность расходов/наград, неизвестный результат COMMIT, живые права при сдаче и торговле, смена клана, откат крафта, стабильные ID и очистка клиентских обработчиков.

Исправлены три подтверждённых слабых места:

- В CI остались два устаревших ожидания: состав бункера Абу без нового A-снабженца и число sparse-обходов после исправления окна квестов. Оба обновлены; проверки состава, подключения обработчиков и допустимых инструкций сохранены.
- В инвентаре оставались неиспользуемые коэффициенты и кэши прежней нормализации износа. Удалены 83 строки; множители 1,5/3/4,5 и заводская прочность сохранены. Вместо проверки мёртвых функций проверяется реальный износ.
- Тестовый скрипт лаунчера выбирал Windows Python для POSIX-публикатора. Теперь проверяет наличие нужного API и использует WSL, если оно недоступно.

Новых подтверждённых обходов оплаты, наград или доступа к базе не найдено. Проверки не заменены пустыми заглушками; реальные обработчики и БД используются для квестов и транзакций. Production-настройки не менялись, merge/deploy не выполнялись.

## Исключения и ручная приёмка

- `data/test_borders.py`: известный дефект main, поселение 447 на клетке границы 5968,1719. Он уже указан в tools/known_failures.txt; география вне релиза не менялась.
- `data/test_orig_misc.py`: локально отсутствует закреплённый исходный texts.xml. Сгенерированный файл вместо него не подставлялся. CI получает оригинал штатным шагом assets.
- `tools/test_deploy_warn.py`: ограничение сигналов/уведомления в WSL1. Все 22 неуспешные проверки совпадают с предыдущим локальным прогоном; штатный server/test_stopwarn.py прошёл и на SQLite, и на PostgreSQL. Падение не скрыто новым исключением CI.

Попытка запускать файловую SQLite из WSL1 на диске D выявила ограничение блокировок DrvFS; этот диагностический запуск не учитывается в итоговом результате. Полный прогон SQLite выполнен нативно на Windows, временные данные и журналы размещены на D. Временные Linux-кластеры и файлы завершённых платформенных проверок удалены.

В игре остаются 12 визуальных сценариев: модели/расположение, подписи, иконки, звук, полосы HP/SP, переходы Flash и ощущение сложности. Получение детали Лаборанта с союзниками и аренда требуют визуального ретеста зависания Flash; автоматические проверки не подтверждают работу самого Flash Player. TC-13 оставлен как справочный план складов. Результаты GitHub Actions следует смотреть в PR.
