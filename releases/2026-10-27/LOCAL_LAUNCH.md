# Локальный запуск текущих Changes в трёх окнах PowerShell

## Готовый комплект тестировщика

Папка: `dist/actual-tester-client`. Запуск — `Start.cmd`.
В неё уже включены клиент, ресурсы, локальный сервер, Python, Flash и
20 тестовых аккаунтов (`accounts.csv`). Это отдельный стенд от описанного ниже.
`state/tester.sqlite` хранит прогресс; при обновлениях его не заменять.

Последующие правки переносить заменой только нужных файлов после остановки
комплекта. Полную пересборку и повторное копирование ресурсов не выполнять;
архив создаёт пользователь. Исправление задержки глобальная карта → локация
уже перенесено в `start.py`: подготовка изображений завершается до открытия
Flash. После перезапуска вручную проверить выход на глобальную карту и
возврат на локацию. Повторный игровой запуск агентом не выполнялся.

## Стенд в трёх окнах

Использует прежнюю отдельную БД `logs/local-review-game/review.sqlite`.
Существующие тестовые аккаунты сохраняются. Аккаунт Review27 из другого
стенда здесь не гарантирован; регистрация: http://127.0.0.1:18080/.
Сначала закрыть Flash и остановить старые локальные серверы через Ctrl+C.
Не запускать одновременно с `tools/local_review.py`.

## 1. Игровой сервер

```powershell
cd 'D:\Projects\lava-reborn\server'
Set-ExecutionPolicy -Scope Process Bypass
. .\logs\local-review-env.ps1
python -B server\server.py
```

Оставить окно открытым. Настройки отключают внешнюю БД, привязывают сервер
к 127.0.0.1:19775, включают локальные тестовые команды и убирают подмену
часов/расписания. Боссы — чётные часы МСК, тюрьмы — 13/17/21 МСК.

## 2. HTTP и сборка клиента

```powershell
cd 'D:\Projects\lava-reborn\server'
Set-ExecutionPolicy -Scope Process Bypass
. .\logs\local-review-env.ps1
python -B logs\local-review-http.py
```

Дождаться `Open http://127.0.0.1:18080/`; оставить окно открытым.
Скрипт пересобирает текущие клиентские правки в
`logs/local-review-game/main.swf`, отдаёт актуальные тексты/карту и не
заменяет установленный `D:\lava-reborn\res\main.swf`.

## 3. Flash Player

```powershell
& "$env:USERPROFILE\Downloads\flashplayer_32_sa.exe" 'http://127.0.0.1:18080/res/main.swf?vversion=1'
```

Войти прежним локальным аккаунтом либо зарегистрировать новый по адресу
выше. Обычный обновляющий лаунчер для этой проверки не использовать.
Требуются ресурсы `D:\lava-reborn\res` и Flash Player по указанному пути.

Для завершения выйти из персонажа, закрыть Flash, затем нажать Ctrl+C в
первых двух окнах. После изменений кода перезапускать оба сервера и Flash;
после изменений только клиентского патча — HTTP (он пересоберёт SWF) и Flash.
Ошибки этих серверов видны в первых двух терминалах: скопировать сообщение
и последовательность действий перед ошибкой.

Ручные проверки: [MANUAL_CHECKLIST.md](MANUAL_CHECKLIST.md). В нём стартовый
раздел описывает альтернативный автоматический стенд с другой БД и Review27;
при использовании этой инструкции брать из чек-листа подготовку персонажа
и тест-кейсы, а не смешивать способы запуска и учётные записи.
