## Настоящий Flash, собственный локальный сервер

Нужны полный набор ресурсов, Flash projector и исходный клиентский SWF.
Пример для текущей машины:

```powershell
Remove-Item Env:LAVA_DB_URL -ErrorAction SilentlyContinue
$env:LAVA_RES = 'D:\lava-reborn\res'
$env:LAVA_FLASH_PLAYER = "$env:USERPROFILE\Downloads\flashplayer_32_sa.exe"
$env:LAVA_CLIENT_MAIN = (Resolve-Path '../main (1).swf').Path
$env:LAVA_HOTKEY_REPORT = 'logs/hotkey-window-matrix-review.json'
python tools/test_hotkey_windows.py
python tools/test_client_audio_flash.py
```

Пробы создают собственные SQLite-базы, тестовый аккаунт, локальный сервер
и скрытый Flash. Настройки `csettings` изолированы; фоновые треки и игровые
звуки у скрытого клиента отключены. Звуковые измерения выполняются на
пустых клипах без аудиоданных. Процессы Flash и сервера завершаются в `finally`.

Матрица хоткеев занимает около полутора минут. Звуковая проверка сравнивает
исходные и исправленные обработчики за два коротких запуска. Отсутствие
`LAVA_FLASH_PLAYER` означает пропуск настоящего Flash, а не подтверждение
его прохождения.

## Ручная приёмка

Текущая инструкция простого запуска и подробный ручной чек-лист:
[MANUAL_CHECKLIST.md](MANUAL_CHECKLIST.md).

`python -B tools/local_review.py` собирает текущие Changes в отдельный SWF,
запускает изолированную SQLite-базу, локальные серверы и видимое окно Flash.
Установленный SWF не заменяет, обновляющий лаунчер не использует.
В отличие от автоматических проб, здесь включён настоящий звук для приёмки.
Актуальные ожидания и ограничения проверки рамок перечислены в чек-листе.

Старые артефакты `dist/release-2026-10-27-review/main.swf` и сохранённые
patch-файлы ниже не включают все последующие изменения. Для актуальной
ручной проверки использовать новый запуск, собирающий рабочие исходники.

Патчи предназначены для чистой базы `8f1ccd89eded6bc992b59dd134c86594a26356e7`.
В текущем рабочем дереве эти изменения уже находятся. Для переноса на чистую
базу сначала выполнить `git apply --check <patch>`, затем применить выбранный
патч. Клиентский и полный патчи — альтернативы для одной базы.

Исходники и тесты находятся в рабочем дереве и могут быть закоммичены после
ревью. Файлы `logs/` и собранный SWF — локальные материалы; они не добавлены
в Git автоматически.
