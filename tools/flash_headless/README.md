# tools/flash_headless — локация в настоящем Flash Player 32, без окон

Необязательная проверка для разработчика: проектор Flash Player 32 рисует
локацию со своими объектами (client/objects/README.md) классами самого
клиента. Работает в docker-контейнере (Wine, виртуальный экран Xvfb, сеть
выключена), окон на рабочем столе не открывает. В CI не запускается: нужны
арт клиента и проектор.

```
LAVA_CLIENT_RES=/путь/к/res \
LAVA_FLASH_PROJECTOR=/путь/к/flashplayer.exe \
bash tools/flash_headless/run.sh локация.xml [папка-вывода]
```

Linux или WSL с docker. Первый запуск собирает образ (нужна сеть).

| Переменная | Что это |
|---|---|
| `LAVA_CLIENT_RES` | `res/` клиента целиком, с `main.swf`; по умолчанию `LAVA_RES` |
| `LAVA_FLASH_PROJECTOR` | проектор; по умолчанию `tools/flash/fp32_sa.exe` |
| `LAVA_OBJECTS` | папка объектов; по умолчанию `client/objects` |
| `FH_WAIT` | сколько секунд ждать, по умолчанию 120 |

Проверяется (`report.txt` в папке вывода): классы клиента загрузились, число
спрайтов совпадает с XML, файлы объектов отданы без 404, каждый экземпляр
стоит в своей клетке и показывает нужную картинку, анимация идёт по кадрам.
Там же снимки: `scene_quarter.png` (вся локация), `inst_*.png` и
`crop_*.png` (каждый объект).

Не проверяется: порядок глубины, ходьба и препятствия, доставка через
лаунчер.
